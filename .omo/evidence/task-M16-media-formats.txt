             pinned primitive topology table + TRS compose T*Rz*Ry*Rx*S.

             (spec embedded as a single-line JSON literal).
- build_script.py / dump_script.py  the committed python templates (reviewable
             as python; dump prints between HARNESS_BLEND_DUMP markers so
             blender startup chatter cannot corrupt extraction).
- extract.rs magic guard -> size cap -> availability gate (typed refusal BEFORE
             any staging) -> staged in.blend + dump.py -> ToolCall scene-dump
             -> marker-bounded stdout -> schema guard -> tree + bounded outline.
- generate.rs from_generation -> staged build.py -> ToolCall scene-build
             (--factory-startup always; `--` passes the output path to
             sys.argv) -> out.blend read ONLY after a zero-exit run.
- verify.rs  profile (eps 1e-5, unordered_at /objects) + extract+diff verdict.

  mock lane drive; without it a dispatched subprocess child would see an empty
  env and the mock modes could not be selected per executor.
- adapter.rs: pub mod blend.

Hermetic lane (harness-test-support, mocktool):
- mocktool/python.rs: tokenizer-level python validation (all quote forms incl.
  triple + raw, escapes, bracket stack with line numbers, control-byte guard).
  HONEST BOUND: a lexer pass, not a full AST parse - python is not guaranteed
  on CI machines and a parser dep is unsanctioned weight for a test mock; the
  realistic breakage classes of a Rust-templated script (unterminated strings,
  unbalanced/crossed delimiters, truncation) are caught; the true py_compile
  equivalence is exercised by the #[ignore] real tier.
- mocktool/blend.rs: blendbuild / blenddump modes - the PARAMETERIZED blender
  stand-in (cwd = executor session temp; blend-build/build.py -> validates
  python -> parses SPEC -> derives census -> writes magic-fixture .blend;
  blend-dump/in.blend -> prints census between dump markers). Three-way
  triangulation: python template, this Rust blender model, and the adapter's
  independent spec->tree projection - the round-trip cross-checks all three.
- mocktool.rs: mode dispatch + validate_python re-export.
