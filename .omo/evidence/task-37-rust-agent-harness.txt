INTEGRATION FACT DISCOVERED (why the entry document is self-contained)
--------------------------------------------------------------
The locked daemon's build_router() wires NO route for /assets/* even
though is_public() admits those paths and web::serve() can serve
them; task-35's QA only ever fetched "/" and "/s/{sid}" (the shell),
so the gap was never exercised. A naive SPA boots to a page whose
every script/link 404s (verified in chromium: net::ERR_ABORTED 404
on all /assets/* subresources). Daemon change is forbidden for this
task, so the boot path was made self-contained: ES module sources
stay byte-identical files (node tests import them directly) while
the built index inlines style/entry module and resolves "spa/*"
imports through data: URLs (CSP requires UNQUOTED data: — 'data:'
quoted is an invalid source expression per chromium, verified).
The registry still publishes every artifact content-addressed, so
the day the daemon adds the route the same bytes serve immutable.
