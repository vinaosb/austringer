RISKS / NOTES FOR LATER TODOS
-------------------------------------------------------------------------------
- The RewindLog seam is intentionally unwired: sessions/loop own the T4
  EventLogWriter handle; through-seq comes from the checkpoint manifests.
- Restore kills live terminals: host responsibility at wire-time (Zed);
  the coordinator's quiet gate is the seam.
- GC deletes refs/manifests; loose git objects remain for the ODB's own
  compaction (refs are the ownership record).
- Snapshot blobs are RAW worktree bytes (no smudge/clean): byte-identical
  restores on CRLF/filter repos; the snapshot tree is deliberately NOT
  the tree git-add would build (recorded via filter_managed awareness).
- Stat-cache reuse trusts (mtime,size) equality - the same trust git's
  index makes; a same-size same-mtime rewrite is missed (raceditor).
- MSVC workaround shell-scoped per T13 recipe; CI/other shells unaffected.
