RESIDUAL RISKS / DISCLOSURES
-----------------------------------------------------------------------
- The lexical router is deliberately conservative: prompts that only
  semi-match a description (e.g. "convert a PDF to markdown" without a
  full USE-FOR phrase) do not route; an LLM-side router later can use the
  same metadata surface. Documented in routing.rs.
- Description-over-cap is tolerated (truncated + warning) for compat;
  name-over-cap stays a hard error. Both documented in skill.rs.
- harness-core NOT depended on (glob reimplemented minimally) — revisit
  after todo 13 lands if richer globs are ever needed in allowed-tools.
- LockMode::Record auto-pins first-seen skills at {root}/.harness/
  skills-lock.json; mismatched pins require an explicit human re-record
  (never auto-rewritten).
