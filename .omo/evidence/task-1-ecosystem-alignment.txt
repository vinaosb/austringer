## Deliberate decisions (record for the reviewer)

1. cost_usd -> cost_usd_micros: Option<u64>, integer micro-USD. The repo's money path is
   integer-only by rule (harness-providers/src/cost: "no floats anywhere in the money
   path"); None = unpriced (CostTable's Unpriced marker).
2. FallbackAsk carries FallbackAskPayload { ask_id, current, proposed, reason, deadline_ms }
   — the FallbackRequest shape plus correlation id and deadline (AskPayload precedent);
   field names current/proposed per the plan text (identity.rs calls them from/to).
   FallbackResolved carries { ask_id, chosen } — ask_id added for client correlation
   (PermissionResolved precedent).
3. FallbackAnswer over the HTTP /cmd route is a typed 400: that route has no per-connection
   identity (the hardcoded "http" wart the plan forbids amplifying). The mediated answer
   path is the WS/IPC pump, which owns the server-assigned per-connection id (the
   'sse-readonly' discipline). The web SPA answers asks over WS primary (POST /cmd is its
   fallback carrier), so no in-repo frontend loses the capability.
4. Deferred (explicitly NOT this todo, no acceptance criterion demands it): composing
   UsageInference into the shipped binary's session factory. ResolvedProvider knows the
   identity but the Inference seam returns no token counts (InferenceAdapter drops
   CompletedTurn.usage), so a production wrap would broadcast invented zeros — dishonest.
   The decorator is the emission path; the cost-ledger wave (todo 33) composes it when the
   seam carries meters.
   [UPDATE 2026-10-21, resume round: RETRACTED AND COMPLETED — the premise was wrong.
   CompletedTurn.usage EXISTS (harness-providers/src/event.rs) and InferenceAdapter
   dropped it at construction (adapter.rs:206). The seam now carries TurnUsage on
   AssistantTurn and the shipped factory emits real counts; see Scenario 8.]
5. verdict evidence = the session event ids the run's watcher observed from kickoff through
   TurnFinished (the ids a Verdict frame can honestly cite today; gate EvidenceLink labels
   are prose, not ids).
6. Verdict frames ride only watched (scheduled) runs — RunSink::spawn_watcher is the only
   emission site, matching "scheduled run verdict emits Verdict frame".
