4. ADVERSARIAL SCENARIOS
------------------------------------------------------------------------
 dst-style clock jumps: backward jump never re-fires (high-water mark;
   unit + runner-level tests); forward jump coalesces to ONE run with
   bounded window and deterministic jitter (catchup_window_stays_bounded
   _after_long_gap, missed_minutes_coalesce_into_one_kick,
   jitter_defers_current_minute_fire_until_effective).
 restart durability: ledger cursors + journal replay — second runner over
   the same root does not re-kick the same minute
   (restart_resumes_cursor_without_double_fire,
   journal_replay_prevents_reexecution_after_restart); a completion
   arriving after restart fails CLOSED (inconclusive, never auto-confirm).
 flaky x3: full suite identical every run (see section 2).
 misleading_success: assertions are on journal steps, runs.jsonl rows,
   MemorySink deliveries and OSC bytes — never on loop ticks.
 stale_state: torn-tail history rows skipped not fatal; corrupt/absent
   ledger loads empty (cursors rebuild from the next fire); corrupt
   pack-tiers file => all-draft => nothing schedules.
 malformed schedule: bad cron typed at register AND at load; draft-tier
   pack typed-rejected (fail-closed incl. on-disk defs); duplicate ids
   typed; kicker QueueFull is a typed RETRYABLE activity error
   (RunnerError::Fire); broken automations.json => daemon serves,
   scheduler idle, loud stderr.
 hung_or_long: watch loops resubscribe on broadcast lag; completion
   watchers exit after TurnFinished; queue-full never blocks the pump.
 notification injection: OSC payloads sanitized (C0/DEL stripped,
   bounded) — embedded escape sequences cannot escape the frame
   (exactly-two-framing-ESCs assertion).
 dirty_worktree: only harness-daemon/** + this evidence file staged;
   sibling workers' files (frontends, plans, skills) untouched.
