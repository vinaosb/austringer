DESIGN DECISIONS (locked, from the recovered transcript + dispatch)
-------------------------------------------------------------------
- ProbeResult is a serde-tagged enum {identified{format, confidence, note},
  legacy_ole2{note}, unknown{note}} (snake_case); LegacyOle2 is the typed
  RED identification for D0 CF 11 E0 A1 B1 1A E1 - matched on the full
  8-byte signature (the plan's 4 bytes are its abbreviation), never parsed.
- Sniff order (fixed): binary magics -> av (flac/ogg-opus/RIFF-WAVE/
  mp3/EBML) -> office zip -> XML root (svg/kml) -> JSON lane -> text
  heuristics. Bytes always win over the name hint (adversarial-pinned).
- svg: root localname svg (any prolog/BOM skipped, ns prefix tolerated)
  OR svg namespace on the root open tag -> Certain. kml: root + 2.2
  namespace -> Certain; ns-less kml root -> Likely ONLY via name-hint
  tie-break, else typed Unknown with a kml-specific note. html is NEVER
  Certain (heuristic lane by the acceptance contract; XHTML falls to the
  html heuristic).
- glTF: partial byte-scan for quoted "asset"+"version" keys + object start
  in the leading 8 KiB window -> Certain (the plan's "partial-sniff"
  wording honored literally, allocation-free). GLB: glTF magic + version 2.
  geojson: full parse (<=512 KiB) with top-level type Feature/
  FeatureCollection -> Likely. json: full parse -> Likely; JSONL: every
  non-empty line parses -> Likely with a JSONL note. The hint map contains
  NO geojson entry: geojson is content-defined, an extension can't create it.
- Text heuristics fire on the leading 8 KiB window; priority when several
  fire is html > toml > csv > markdown; the hint may only SELECT among
  candidates that fired (markdown hinted .csv stays markdown - pinned).
- Ogg: OggS + OpusHead found in the first 256 bytes -> opus; else ogg.
- mp3: ID3 prefix OR guarded frame sync (0xFF + 0xEx mask + version/layer
  validity + bitrate != 0/15 + samplerate != reserved). UTF-16 BOMs
  (FF FE / FE FF) are explicitly excluded - they pass the raw sync mask.
- EBML: earliest of "webm"/"matroska" in the first 256 bytes -> webm/mkv
  Certain; neither -> hint tie-break at Likely, else typed Unknown.
- geotiff = the tiff lane (II*/MM*, BigTIFF 0x2B noted); the note states
  geokey verification is extract-lane business. geopackage = sqlite magic
  + GPKG application_id at 68..72. parquet = PAR1 head AND foot (len>=8).
- zip dep: zip 8.6.0, default-features = false, features = ["deflate"]
  (pure-Rust deflate: flate2/zlib-rs/zopfli - no C, MSVC-clean), optional,
  tied to the `office` feature; declared directly in harness-media/
  Cargo.toml (precedent: the 48 tree-sitter grammar deps local to
  harness-ast). Dev-dependency self-reference
  `harness-media = { path = ".", features = ["office"] }` makes the bare
  QA command cover the office lane via feature unification while the
  library default stays feature-empty. cargo tree confirms zip is ABSENT
  from the default-feature graph.
- probe registry (the todo's title): probe::registry() registers all 34
  descriptors (probe Supported; extract/generate/verify Unsupported with
  honest reasons naming the adapter todos), per M1's descriptor.rs promise

   order "2-char version + pointer-size + endianness + flags" is garbled;

   module doc + this evidence record the deviation. There is no flags
   byte in the real format.

   documented "returns false (and keeps the existing entry)" but the

   doc/impl split shipped. probe_registry's duplicate-registration test
   pinned the documented contract (red against the M1 impl), and
   descriptor.rs now uses the entry API: Vacant inserts, Occupied keeps
   the original and returns false. Root-cause fix, not a test weakening.
