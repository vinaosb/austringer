4. Deviation found and resolved during test development (lsp hermeticity)
--------------------------------------------------------------------------
The first lsp_query e2e used a .py fixture. On THIS machine a foreign-venv
`pyright-langserver.exe` sits on PATH; a bounded standalone probe proved the
executor itself works and is fast:
  PROBE elapsed=1.0061827s outcome=Ok("(variable) value: Literal[1]")
...but the test process then hung >19min in runtime teardown (spawned pyright
child + kill_on_drop on a current-thread test runtime; harness-lsp's own suites
never spawn real servers — that's what set_server_factory exists for).
Resolution: the e2e uses an unroutable `.zzz` extension — the router's typed
NoServer error through the bound executor, hermetic and fast on every machine.
Recorded in .omo/notepads/ecosystem-alignment/issues.md.
