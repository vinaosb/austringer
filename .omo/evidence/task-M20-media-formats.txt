WHAT LANDED
-----------
harness-media/src/adapter/step/ (new, unconditional - no codec dependency,
no feature gate; mirrors the blend lane):
- mod.rs      module docs + honesty rows + ENGINE/TOOL/EXTRACT_SCHEMA/
              DUMP_SCHEMA/BUILD_SCHEMA consts + StepProjector +
              register_projections (M10 seam - pure, no tool needed).
- spec.rs     StepSpec/SolidShape(box|cylinder|sphere)/SolidSpec/Transform
              + strict from_generation (InvalidSpec on format mismatch,
              non-finite floats, non-positive/oversize dimensions >1e6,
              duplicate/oversize/non-printable names, >MAX_SOLIDS=128).
              serde rename_all lowercase: the wire/spec/python/mock key
              form is "box"/"cylinder"/"sphere" per the plan.
- tokenizer.rs  the scanner: record-oriented pass (strings with '' escapes,
              /* */ block + -- line remarks skipped, #refs/.ENUM./numbers
              as words, ';'-terminated records); caps: 1M records, 4 KiB
              per string capture, caller budgets (input size + wall clock)
              -> typed ExtractTooLarge; missing END marker / unterminated
              string or remark / malformed #-record -> ParseFailure.
- interpret.rs  the census interpretation: entity-type counting (complex
              instances count every constituent), PRODUCT chain links,
              SI_UNIT enum joins ("MILLI/METRE") + CONVERSION_BASED_UNIT
              names, CARTESIAN_POINT numeric-tuple bbox accumulation;
              caps 4096 types / 1024 products -> ExtractTooLarge.
- extract.rs  the M6 ExtractHandler signature: magic gate -> scan ->
              canonical sorted-key tree {schema, header{file_description,
              file_schema}, entity_count, entity_census, products[{id,
              name, formations, definitions}], units[], bbox} + the
              bounded structure-summary projection (<=2000 chars).
              FILE_NAME never enters the tree (wall-clock stamps are not
              structural facts).
- tree.rs     the INDEPENDENT spec->tree projection (M5 provenance rule):
              topology_tree (per-solid faces/edges/vertices from the
              pinned table, analytic volume, EXACT analytic world bbox -
              box = rotated corners; sphere = rotation-invariant interval;
              cylinder = per-basis support function with axis a = R*z).
- script.rs   include_str! versioned templates + deterministic
              builder_script() (single-line embedded JSON, placeholder
              __SPEC_JSON__).
- build_script.py  the freecadcmd builder: Part.makeBox/makeCylinder/
              makeSphere + App.Placement (euler XYZ radians, composed
              Rz*Ry*Rx via axis-angle multiply), single compound
              exportStep (AP214-flavored), then a post-export regex pass
              pinning the FILE_NAME clock to the embedded epoch (M1
              determinism contract).
- dump_script.py   the freecadcmd topology re-read: Part.Shape().read,
              per-solid Faces/Edges/Vertexes/Volume/BoundBox census JSON
              between HARNESS_STEP_DUMP markers (tolerant of startup
              chatter).
- generate.rs spec -> builder script -> ToolCall(freecadcmd, step-build,
              {script},{output}) -> bytes; availability gate BEFORE
              staging (typed ToolUnavailable when freecadcmd is not opted
              in/installed); output read only after a zero-exit run.
- verify.rs   stage -> ToolCall(freecadcmd, topology-dump, {script},
              {input}) -> census between markers + versioned schema guard
              -> structural_diff(expected, census, profile) -> verdict;
              profile: float_epsilon 1e-4, NO unordered paths (spec-driven
              solids are ordered-exact - the M5 rule), FILE_NAME never in
              the census (the plan's strip-by-design). read_topology_census
              is the public seam the schema-pin test uses.

harness-test-support/src/mocktool/step.rs (new; the parameterized
freecadcmd stand-in while the golden stays pending - M16 blend
precedent): `stepbuild` reads step-build/build.py, validates it as
