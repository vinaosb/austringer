DESIGN NOTES
-------------------------------------------------------------------------------------
- Producer ids in the M4 derived store: deterministic `deterministic:{format}`;
  model-mediated `model:{model-id}:{PROJECTION_PROMPT_VERSION}` (v1) — the prompt
  template version is the material generation param, so provenance carries model id +
  params per the MUST-NOT. Every resolution ALSO writes the canonical delivery alias
  (`delivery`, == harness-providers DELIVERY_PROJECTION_PRODUCER, equality pinned in
  tests) so the M8 delivery cache inlines at request-build time.
- Resolution order per (media, kind): delivery alias -> deterministic registry ->
  model producer cache -> capability-gated model call. Cache hits short-circuit BEFORE
  any model call (counter-pinned); capability check (vision/audio_input mapped from M7)
  ALWAYS precedes a model call (MUST-NOT, counter-pinned from both arms).
- Model-mediated prompt: single Event::User{blocks:[original media block]} + per-kind
  focus instruction; non-text or empty assistant turns are typed failures — never
  fabricated transcripts (MUST-NOT). Per-call wall-clock timeout -> Unprojectable::Timeout,
  marker survives, nothing stored.
- Notices: Unprojectable carries notice() text naming mime + kind (the daemon submit hook
  appends it as Event::System when the M9 merge lands; the text is produced + pinned now).
