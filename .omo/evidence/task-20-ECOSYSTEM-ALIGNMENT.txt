What landed
-----------
(a) Session-history panel (ui.js historyPanel): scheduled-run rows from
    GET /s/{sid}/history (task-2 route; RunRecord {automation_id,
    session_id, fired_at_minute, outcome, verdict, network}), per-session
    cost/model totals accumulated from v2 usage frames, gate Verdict
    frames with evidence links that seek the replay log to the cited
    frame id, and state.resolvedLog finally rendered ("asks answered").
    Empty-state: "no scheduled runs recorded for this session" — never a
    spinner (typed 404 and fetch failures land in the same empty-state).
(b) Changed-files-by-turn timeline (ui.js timelinePanel): Diff events
    grouped under the turn that produced them (store tracks turn from
    TurnStarted frames; timeline = [{turn, path}]).
    Receipts: OpenCode #55064 Changed-files-by-turn; Devin Session
    Insights timeline.
(c) Workers panel: rendered from state.workers since t15 (Warp
    precedence port); e2e now proves it non-empty with fixture children
    (ChildStarted/ChildProgress/ChildFinished/TeamBudget frames seeded
    into the attach-snapshot ring by the e2e daemon fixture).
(d) Collapsed-by-default transcript with per-entry "focus" expand
    (receipt: Claude /focus; 5-project one-line-per-entry convergence).
    Single-line preview (140 chars) collapsed; full text on expand.
(e) Trends panel moved into the session view (it can never have data on
    the unattached dashboard) and fed by v2 usage frames: total cost,
    cache-hit %, per-model frame/cost mix. The stale "cost / cache /
    eval scores: not carried by protocol v1" confession is DELETED.
    Composer hint's stale "protocol v1" wording corrected.
(f) FallbackAsk + PlanAsk answer UI reusing the gates surface:
    keep-current / switch-to-proposed buttons send
    {type:"fallback_answer",ask,chosen} (identity echoed verbatim — the
    mediator accepts only exact matches, garbage resolves deny-side);
    approve/reject buttons send {type:"plan_answer",ask,decision:"approve"|"reject"}
    (PlanDecision is externally tagged: bare strings on the wire).
    Store also maps the v2 SessionEvents cost_warning/cost_stop/plan_*
    to notifications with the compat.rs kind names (not anomalies).

Protocol negotiation
--------------------
proto.js PROTOCOL_VERSION 1 -> 2 (the "flipping a web client proposing
1 is IN-SCOPE" clause); SSE fallback URL now carries &version=2 (the
SSE wire has no Hello — v2 is query-opt-in per server.rs TokenQuery).
hello_ack version renders as a [data-testid=proto-version] badge.

Fixture (harness-web/examples/e2e_daemon/daemon.rs)
---------------------------------------------------
- factory() is now identity-bearing: ComposedInference{ identity: Some
  (anthropic/claude-sonnet-4-5) } so the daemon's UsageInference
  decorator broadcasts priced per-turn frames (TurnUsage 1200/80/6400/0
  -> 6720 micro-USD per inference via the builtin price table).
- seed_fixtures(): one confirmed RunRecord per fixture session in
  {data}/runs.jsonl + five team frames retained in each ring.
- Seeded into TWO sessions (e2e, e2e-drill): the drill scenario needs a
  fresh scripted stack — the engine runs NO inference after a completed
  task (discovered live: turn 2 on a task_completed session publishes
  turn_started/turn_finished but zero transcript events and no usage
  broadcast), so scenario 1 (todo 37) keeps session e2e's only turn and
  the todo-20 drill owns e2e-drill's turn: ask -> echo -> diff + exactly
  two live usage frames = $0.013440.
- harness-web Cargo.toml gains dev-dep harness-providers (ModelIdentity
  for the fixture identity; versioned path dep per cargo-deny). This is
  the one Rust delta beyond JS; it is inside harness-web, no daemon code
  touched. ("No Rust changes expected" was not achievable: the history
  verdict row, the workers children, and the priced usage frames the
  acceptance criteria assert cannot exist without fixture data, and the
  fixtures live in this example.)
