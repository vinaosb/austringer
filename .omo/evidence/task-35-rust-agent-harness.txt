1. WHAT LANDED (scope clause → module map)
────────────────────────────────────────────────────────────────────────
All 15 binding clauses implemented in harness-daemon (src split, every
file ≤250 code lines excluding #[cfg(test)]):

 1. TRANSPORTS — axum WS (`ws.rs`, `server.rs`), SSE (`handlers.rs`),
    interprocess local-socket IPC named pipe on Windows / UDS on Unix
    (`ipc.rs`). ONE typed client protocol (`protocol.rs`, v1, internally
    tagged, bounded decode) driven by ONE transport pump (`transport.rs`)
    shared by all three transports.
 2. MULTI-CLIENT ATTACH — `attach.rs` (SessionHost + client registry +
    per-session cap) + `events.rs` (EventHub: monotonic ids, bounded
    replay ring). Shared permission queue: the ask broadcasts to every
    attached client; ONE valid answer resolves for ALL
    (`mediation.rs` — verified byte-level in tests below).
 3. WEB ASSETS — `web.rs` serves harness-web bytes (placeholder SPA)
    with content-type + cache headers (no-cache for HTML entry, immutable
    for hashed artifacts). Asset registry added to harness-web lib
    (disclosed; the assets crate is the designated owner).
 4. AUTH — `auth.rs`: 127.0.0.1 bind + generated 32-byte token
    (hex, OS entropy), PEER-ADDRESS trust (loopback check on the
    kernel-reported peer), NEVER Host-trust — plus a defensive Host
    allowlist (loopback names only) so rebinding probes are refused
    before token evaluation. Negative regression tests pinned (below).
 5. URL-ADDRESSABLE SESSIONS — stable ids in routes: GET /s/{sid} (SPA
    deep-link page, public), /s/{sid}/attach (WS), /s/{sid}/events
    (SSE), /s/{sid}/cmd (POST). Deep-link test pinned.
 6. MULTI-CLIENT PERMISSION MEDIATION (Qwen §18) — `mediation.rs`:
    4 policies (FirstResponder default, Designated, ConsensusQuorum
    fail-closed on any deny, LocalOnly), CANCEL-VOTE sentinel (any
    client withdraws a pending ask; malformed ids typed-rejected,
    untrusted ids never reach the mediator — auth layer), N1
    synchronous-timeout invariant: exactly one of answer XOR cancel XOR
    timeout ever resolves (resolve_once gate under mutex; race between
    timeout arm and late answer yields the winner, never double).
 7. TYPED SSE EVENT SCHEMA + RESYNC — `events.rs` + `protocol.rs`:
    monotonic gap-free ids, bounded replay ring (configurable capacity),
    slow-client eviction (broadcast Lagged → StateResyncRequired +
    Snapshot; delta-skipping reducer: clients behind ring head skip
    deltas and resync without losing the session).
 8. ACTIVE-SESSION REGISTRY — `registry.rs`: PID-keyed entries with
    boot-id liveness proofs reusing T24's LeaseProbe
    (SysinfoLeaseProbe prod / FakeLeaseProbe tests); sweep reaps
    PidDead / HeartbeatStale / BootIdChanged.
 9. SCHEDULER + NOTIFICATION EMITTER — `scheduler.rs`: hand-rolled
    five-field cron engine over epoch minutes (JUSTIFIED over the `cron`
    crate: no chrono dependency, pure integer math, deterministic under
    injected clocks — flaky-immune; UTC-minute alignment documented,
    DST/local firing is T41). Bounded catch-up (1 day). `notify.rs`:
    typed NotificationSink trait + fan-out Notifier (TracingSink,
    MemorySink now; OSC 777 + system notifiers land T41 on the same
    trait — per plan).
 10. DURABLE-EXECUTION OPTION (Cursor Temporal §19 pattern, NOT the
    dependency) — `journal.rs` (steps, content-addressed activity ids =
    blake3(name‖input), append-only JSONL, torn-tail tolerant),
    `durable.rs` (TurnWorkflow: begin/finish, signal_with_start
    Started/Delivered, child workflows in their own journal files),
    `activity.rs` (JournalingExecutor replay-first; retry_activity
    retries the ACTIVITY, never the inference). DEFAULT ON
    (DaemonConfig.durable = true), journals under
    {data}/journal/{session}/{turn}.jsonl. Overhead: one JSONL append
    per step + fsync on turn boundaries only. Production-history replay
    test: a NON-DETERMINISTIC executor is consulted ZERO times when the
    journal covers the history. The T5 loop runs inside the turn
    workflow harness (`engine.rs` run_turn ↔ TurnWorkflow).
 11. REMOTE-WORKER SPLIT-BRAIN (Cursor §19) — `worker.rs`: agent loop
    stays in the daemon; tool execution routes to workers over
    OUTBOUND-ONLY connections (workers dial IN to /worker; no inbound
    ports on the user side). stdio MCP stays worker-side, HTTP MCP
    proxied by the daemon (route_mcp). CREDENTIALS NEVER CO-LOCATED:
    the DaemonToWorker vocabulary has no credential-capable field —
    pinned by wire-shape test; workers get scoped ToolGrants only;
    ungranted tools fail closed (NotGranted). Worker drop mid-tool is
    typed (WorkerDropped) and the session continues (split-brain
    preserve tests).
 12. OUTPOSTS RECONCILIATION (Devin §22) — `outposts.rs`: ClaimLedger
    over NAMED QUEUES; claim_next FIFO with deadline; sweep() expires
    claims and RE-ENQUEUES the session (self-heal); healed sessions
    reclaimable by another worker.
 13. ZERO-DOWNTIME RELOAD (jcode §32) — `reload.rs`: unix keeps true
    exec() semantics (same PID, fd passed with CLOEXEC cleared);
    Windows performs SOCKET HANDOFF BY INHERITANCE (SetHandleInformation
    + spawn + adopt; proven across a real process boundary in
    reload::tests::socket_handoff_survives_process_boundary — child
    adopts the handle, accepts, echoes). DIVERGENCE DISCLOSED: Windows
    has no exec(); the successor is a new PID holding the SAME socket
    (zero-downtime for clients; PID continuity is unix-only). Successor
    Winsock lazy-init handled (WSANOTINITIALISED 10093 found + fixed in
    QA — probe log in evidence §6). STALE-SOCKET REAPING: the IPC
    listener uses GenericNamespaced names (abstract namespace on Linux,
    \\.\pipe\ on Windows) — no filesystem socket corpses exist by
    construction; dead-process reaping is the registry's job (§8).
 14. OPTIONAL OTel EXPORT (Grok posture) — `otel.rs`: DOUBLE opt-in
    (config.enabled AND env HARNESS_TELEMETRY=1 AND endpoint), 4
    independent content gates (prompts/responses/tool_details/
    tool_content) all closed by default (content-free), secret-scrubbing
    (sk-/ghp_/xoxb-/AKIA/Bearer-eyJ shapes), mTLS-ready config surface
    (MtlsConfig validated, wiring documented for T41), fire-and-forget
    HTTP transport (telemetry never fails the daemon).
 15. ACCEPTANCE — two simultaneous clients see IDENTICAL state
    (byte-level frame equality asserted over a real axum server AND the
    real binary); permission answered once applies to both; NEGATIVE:
    spoofed Host + no/invalid token refused (401/403) — regression
    tests for the CVE-2026-82533 class.

Composition (no re-implementation): AgentLoop hosted per session
(`engine.rs`) with the T7 InspectorChain over Default (empty) rules →
everything ASKS → routed through MediatedAskPolicy (the daemon's ask
seam) — wrapped in ReservedAwareApproval so the loop-reserved
task_completed signal never asks (bug found by red test: two asks per
turn incl. the reserved tool; fixed + regression-covered). Tool
execution = WorkerToolExecutor (split-brain + journaling + diff
forwarding onto the event stream). Sessions/journals/leases compose T24
primitives; the binary factory injects an UnconfiguredInference stub
until T40 wires the T9 provider (frontends + protocol fully exercisable
without a provider; disclosed in the stub's error text).

4. ADVERSARIAL SCENARIOS
────────────────────────────────────────────────────────────────────────
 cancel/resume: client disconnect mid-ask → ask times out N1-exactly-once
   (mediation::synchronous_timeout_resolves_once, paused time); worker
   drop mid-tool → typed WorkerDropped, session + replacement worker
   continue (worker::worker_drop_mid_tool_is_typed_and_session_continues;
   stages::worker_executor_surfaces_failure_as_tool_text).
 malformed: protocol garbage frames → typed MalformedFrame error, 3
   strikes → close (ws_e2e malformed test; ipc same path); oversized
   frames rejected before parse (protocol::oversized_frame_rejected_
   before_parse); IPC reads hard-bounded per line (ipc.rs read_bounded_
   line).
 untrusted text: ALL client input bounded before parsing
   (protocol::validate_client: text ≤64KiB, ids ≤128 printable);
   asserts never echo untrusted bytes.
 hung_or_long: idle read timeout (config) → Bye + close, session
   survives (ws_e2e idle test); slow-client eviction (above); worker
   call timeout typed (WorkerRouter.call_timeout).
 flaky ×3: scheduler + mediation run on injected clocks (paused tokio
   time / epoch-minute math); full suite ×3 identical (§2).
 stale_state: resync correctness (events.rs suite: behind-ring-head →
   resync, inside-ring → exact delta, live continues after resync);
   registry reaping (dead pid / stale heartbeat / reboot).
 repeated_interruptions: per-session attach cap (default 64) bounds
   reconnect storms (client_cap_bounds_attach_storm); broadcast is
   bounded capacity (lag → resync, never unbounded buffers).
 misleading_success: byte-level frame equality across clients asserted
   (not just "both got something"); protocol roundtrips + determinism
   of encoding pinned; production-history replay asserts ZERO inner
   executor calls (non-determinism guard).
 dirty_worktree: only task-35 files staged (root Cargo.toml/Cargo.lock,

6. DISCLOSURES & BUGS CAUGHT BY QA
───────────────────────────────────────────────────────────────────────
 • Windows reload: PID changes (no exec on Windows); socket continuity
   proven cross-process. Unix = true exec (same PID), cfg-gated.
 • Winsock lazy-init: a successor that adopts a socket before any
   network call hits WSANOTINITIALISED (10093); fixed in adopt() via a
   throwaway UDP bind (std's one-time WSAStartup), zero FFI.
 • tokio from_std requires non-blocking sockets: the binary initially
   served nothing (kernel accepted via backlog; reactor never fired);
   fixed with set_nonblocking(true) before from_std. Found in manual QA.
 • SharedSteerer initially shadowed the loop's own submit queue (turn
   prompts never recorded as user events) — caught by the binary QA
   transcript, fixed (drains both queues), regression-covered.
 • Engine events publish at turn boundaries (AgentLoop owns its event
   mirror inside run()); permission asks stream LIVE mid-turn through
   the control bus. Documented; mid-turn event streaming is a T36 input.
 • Binary ships an UnconfiguredInference stub (provider wiring is T40);
   all protocol/attach/auth surfaces fully exercisable without one.
 • Binary does not yet run the scheduler/registry sweep loops (modules
   + tests land now; long-running composition belongs to T41 cron-of-
   packs which consumes them).
 • LOC accounting: code lines exclude doc comments/blank lines; every
   file ≤250 (largest: otel.rs 233). No unwrap/expect/panic! in any
   non-test src (grep-verified).
 • MSVC env workaround (task-13/29 recipe) shell-scoped for every
   invocation; private target dir target-task-35; nothing repo-side.
 • Worktree isolation proof: see §7 (appended post-commit).
