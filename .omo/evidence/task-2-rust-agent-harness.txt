Deliverables per plan todo 2 (a)-(f):
  (a) provider/ — rule-based fake provider, goose DummyApi pattern:
      FakeApi::on(matcher).reply_stream(script) / .fail_no_choices() /
      .fail_output_limit() / .fail_context_limit() / .fail_server_error() /
      .reply_then_server_error(script) / .up_to_n_times(n);
      matchers: Any / Model / PromptContains / All (From<&str> = PromptContains);
      first-match-wins rule engine with use-caps; unmatched requests return the
      typed ProviderError::UnexpectedRequest (never panics).
  (b) sse/ — codex responses.rs pattern: ev_message_start / ev_message_stop /
      ev_text_delta / ev_tool_call_delta / ev_usage / ev_error / ev_done
      constructors; SseScriptBuilder (ordered steps, .delay(), .up_to_n_times(n)
      = repeat steps up to n times, .build()); SseParser (consumer side, exposes
      pending_fragment()/is_mid_event() for torn-frame observability).
  (c) sse/stream.rs — SseByteStream: chunked in-memory body; drop_after_bytes(n)
      tears the final frame mid-event (partial event stream observable);
      close_after_events(n) ends cleanly after n whole events (no torn frame,
      later events incl. done never arrive); inter-chunk delays for idle-timeout
      paths (virtual under start_paused).
  (d) gate.rs — ResponseGate: Condvar-style async gate; race-free wait via
      Notified::enable() BEFORE state check + notify_waiters; release() /
      cancel() (sticky, release-already-seen wins) / wait_for(timeout) /
      is_released().
  (e) cassette/ — CassetteRecorder (redaction applied AT RECORD TIME so a
      cassette never holds unmasked secrets; BTreeMap => sorted keys,
      deterministic JSON); Cassette::save/load (Corrupt error carries path +
      serde line/column); CassetteReplayer STRICT: order-based matching
      (Mismatch on wrong turn), Exhausted when dry, finish() dies on unused
      interactions with count; RedactionFilter (default: authorization/x-api-key/
      api-key/cookie headers -> [REDACTED]; .mask_value(needle) scrubs substring
      from prompt AND every event payload via recursive JSON walk).
  (f) Hermetic by construction: zero networking stack in the dep tree (tokio
      features sync+time only), all streams in-memory. DESIGN CHOICE (documented
      per plan): NO loopback servers, NO HTTP-mock dependency — in-memory
      streams/channels give full HTTP-shape fidelity (chunked frames, torn
      frames, idle gaps) without sockets. Timer tests run under
      #[tokio::test(start_paused = true)] — zero real sleeps anywhere.
  util.rs — TestDir: per-test tmp dir keyed tag+pid+counter (nextest = process
  per test), removed on drop. Isolation test proves same-tag dirs collide never.
