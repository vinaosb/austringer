DELIVERABLE (per plan lines 112-115)

harness-core/src/event/media.rs (208 pure LOC, <=250):
  - store_media(bytes) -> io::Result<MediaRef>: content-addressed store
    for ANY payload via the existing write_atomic pattern; NO dimensions
    (image-specific, stay on store()/image path); identical bytes dedup
    by exists() exactly like store().
  - write_atomic + ContentHash::hex widened to pub(super) so the sibling
    derived module reuses the SAME atomic-write + filename discipline
    (no copy). Module doc generalized; image path byte-identical.

harness-core/src/event/derived.rs (NEW, 201 pure LOC, <=250):
  - ProjectionKind {TextProjection|Transcript|Thumbnail|SceneDescription},
    serde snake_case ("transcript", ...), const as_slug() + Display.
  - DerivedStore::open(session_dir) -> <session>/media/derived/
    {artifacts/,manifests/} (root composed from MediaStore::DIR_NAME).
  - store_derived(source, producer, kind, bytes) -> io::Result<MediaRef>
    (4 args: the plan-mandated signature, plan line 112):
      * producer validated at the boundary: 1..=128 bytes
        (MAX_PRODUCER_BYTES), else typed io InvalidInput;
      * artifact = content-addressed projection bytes (dedup by exists,
        shared pool across ALL entries - identical projections across
        keys are ONE file);
      * manifest = JSON {source, producer, kind, created_ms (unix ms),
        artifact {hash, bytes}} written LAST via write_atomic -> the pair
        is crash-safe: a crash between the writes leaves an ignorable
        orphan artifact, never a dangling reference;
      * dedup fast path: an already-valid entry holding exactly these
        bytes writes NOTHING (created_ms stays byte-stable); a corrupt
        manifest on the write path is overwritten (repair), not an error;
      * re-store same key with NEW bytes: manifest repoints at the new
        artifact; superseded artifact deliberately KEPT (MUST-NOT-GC,
        plan line 112 - retention is later work).
  - load_derived(source, producer, kind) -> Result<Option<Vec<u8>>,
    DerivedCorrupt>: plain miss (no manifest) = Ok(None); structural
    problems = typed variants, never silent:
      Malformed (invalid/truncated JSON) | KeyMismatch (manifest fields
      != lookup key) | MissingArtifact (manifest w/o artifact on disk) |
      ArtifactHash (artifact bytes hash != manifest claim) | Io.
  - Manifest filename: {source-hex}.{producer-slug}-{blake3-tag8}.
    {kind-slug}.json; producer_slug folds unsafe chars to '-' and appends
    an 8-hex blake3 tag of the RAW id so distinct producers that sanitize
    identically (e.g. "whisper:cpp" vs "whisper-cpp") never share a
    manifest file (test-pinned; hostile ids stay single path components).
  - Projections never touch the JSONL: DerivedStore writes only under
    media/derived/ (test asserts the session root contains only "media").

harness-core/src/event/mod.rs (131 pure LOC): pub mod derived + re-export
DerivedCorrupt/DerivedStore/ProjectionKind. Additive; zero changes to
existing serialized forms (full event suite green).
