Transcript format: JSONL; {"dir":"c2s","await":<marker>,"raw":<exact
bytes>} client frames (barrier = server frame containing marker must be
observed first), {"dir":"s2c","raw":<exact wire bytes>} server frames,
{"dir":"srv","action":"publish_image_event"} server-side scripted
actions the replay harness re-performs. raw strings are the literal wire
bytes - never round-tripped through serde_json::Value (whose BTreeMap
would scramble struct field order; verified during capture: encode_client
emits struct order, json!() emits sorted order - they differ).

Coverage (plan M9 "all three handshake sites"):
  - ws.rs initial Hello (version 1) + resync/snapshot + hello_ack
  - ipc.rs initial Hello (version 1, session-bound)
  - transport.rs mid-session in-stream re-Hello (v1, silently accepted)
  - command submit -> full turn frames (turn_started, recorded user
    text, assistant, tool_call task_completed, tool_result, turn_finished)
  - RECORDED IMAGE-BLOCK EVENT on the wire (id 7, seq 900, blake3:bd73...)
    published through SessionHost::publish - the same path the engine
    driver uses for recorded events; the v1 protocol has no client-side
    image submit, so this is how such frames enter the v1 wire.
  - ping/pong

Determinism: fixed token, fixed client/session ids, CompleteOnlyInference
(task_completed is loop-reserved - no worker needed), fixed image payload
b"harness-v1-corpus-image-payload" -> fixed hash. Byte-stability of every
frame through decode/encode round-trip asserted INSIDE the capture tool
before writing (v1 codec oracle property).

FANOUT AUDIT (plan M9: "no fanout path may cache encoded frames shared
across connection versions"): audited EventHub.publish (events.rs) and
the control bus (mediation.rs control_bus) - both broadcast TYPED
ServerMsg values; encoding happens per-connection at each carrier's
writer (ws.rs writer task encode_server, ipc.rs write_line, handlers.rs
sse unfold). NO cached/shared encoded frames exist. The downgrade
therefore lands per-connection at the pump funnel (transport.rs) where
every carrier's outbound passes with the negotiated version in hand.
No fix needed; noted per plan.
