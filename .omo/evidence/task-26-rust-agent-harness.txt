WINDOWS MECHANISM (probe-tested, honest record — 6 probe iterations)
--------------------------------------------------------------------
Chosen: AppContainer. Rejected routes, all empirically:
- CreateProcessAsUser + restricted token (CreateRestrictedToken
  DISABLE_MAX_PRIVILEGE, no IL change): ERROR_PRIVILEGE_NOT_HELD (1314)
  for standard users on this build.
- Same + low IL, same + Users/BUILTIN restricting SID: 1314 regardless.
  (Also learned: capability SIDs like S-1-15-2-1 are rejected as
  restricting SIDs — CreateRestrictedToken err 87.)
- SetTokenInformation(TokenAppContainerSid): ERROR_INVALID_PARAMETER
  (87) in both orderings (IL-before/after) — dead end; the kernel builds
  the LowBox token from the spawn attribute instead.
- AppContainer attribute + CREATE_SUSPENDED: child NEVER completes init
  (hang -> 10s timeout). Backend spawns UNSUSPENDED; job assigned
  immediately after (T19's documented microsecond window).
- AppContainer attribute + custom lpEnvironment: ERROR_ENVVAR_NOT_FOUND
  (203), even for a 1-var UTF-16 block. Isolated by probe matrix:
  AC+NULL-env works, plain+env works, AC+env fails. Consequence: this
  backend CANNOT scrub/override env at spawn; it reports env_scrubbed
  false + a named env_scrub gap (scrub stays a real, tested policy
  enforced at the exec-layer command seam, todos 19/27).
Kernel semantics learned (all probe-verified):
- AppContainer access checks are dual-principal: an object needs a
  package-SID GRANT; deny ACEs for the package SID do NOT subtract.
  Protected paths are therefore enforced by marking their DACL
  PROTECTED (0x80000000 — not 0x800, which silently does nothing) which
  strips/blocks inherited grants; the deny ACE stays as belt+suspenders.
- The kernel never strips inherited-flagged ACEs from a caller-provided
  DACL; the icacls /inheritance:r client-side filter is reimplemented
  (strip_trustee_aces walks the ACL and drops package-SID ACEs).
- Profile SIDs from CreateAppContainerProfile free with FreeSid
  (LocalFree = heap corruption — found via STATUS_HEAP_CORRUPTION crash
  and fixed); GetNamedSecurityInfoW DACL points INTO the security
  descriptor — free the descriptor, never the interior pointer.
