RESIDUAL RISKS / NOTES
----------------------
- Offset-based replay suppression assumes the resume replay is identical up to the offset
  (prefix-cache-backed replays are; the FakeApi replays byte-identically). DIVERGENT
  replays re-emitting an executed call PAST the window are caught by the dedup registry
  (proven in chaos_dedup.rs); divergent TEXT past the window is inherently non-dedupable
  and is treated as new content (documented in turn.rs module docs).
- InferenceError's payload is still String at the harness-core seam ("Todo 9 replaces the
  payload with typed variants" per its doc comment); core is frozen for this task, so the
  adapter renders the typed error faithfully into Failure(...) — the typed surface lives in
  harness_providers::error and is asserted directly in the chaos suites. Migration of the
  core enum is a 1-line core change for whoever next owns harness-core.
- RetryExhausted/ResumeExhausted last-error boxes are Box<ProviderStreamError> (recursive
  type); PartialEq derives make them fully assertable in tests.
- Real-transport adapters (todo 10) reuse wire.rs + provider.rs EventSource; the FakeBridge
  stays a test instrument (tests/common) by design.
