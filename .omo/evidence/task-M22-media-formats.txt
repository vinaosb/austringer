DEVIATION NOTES
---------------
1. Arrow MIME: the plan names application/vnd.apache.arrow.stream; the landed
   M2 registry row (authority for descriptors) registers Arrow as
   application/x-arrow-ipc (the file-format MIME - matching the ARROW1 magic
   lane this adapter implements). Descriptor left untouched.
2. "typed UnsupportedCompression" (plan letter) is implemented as the EXISTING
   MediaError::UnsupportedFeature { feature: "compression:ZSTD" } - the M12
   compressed-primitive refusal the same plan section cites as the pattern
   (References: "codec honesty mirrors M12"); avoids a shared error.rs hunk
   and keeps one honesty vocabulary.
3. Arrow verify "Schema::eq + batch byte lengths": Schema::eq is folded into
   the verdict (mismatch -> changed /schema node); "batch byte lengths" is
   implemented as the per-batch {rows, columns} census in the diffed tree +
   re-read - the arrow-ipc reader API does not expose per-message IPC body
   byte lengths, and row/schema equivalence is the semantic contract.
4. Local rustfmt (1.9.0-stable, 88d9e12ae1) disagrees wholesale with the
   committed corpus (it also flags audio.rs/json.rs at HEAD - pre-existing,
   env-specific): my files follow the corpus conventions (version-sort import
   ordering, short struct literals inline) as committed; CI's formatter is
   authoritative.
5. Type surface honesty: extract refuses columns outside
   bool/int32/int64/double/utf8 typed (UnsupportedFeature column-type:<T>) -
   v0.2's deliberate bounded surface, disclosed in the module honesty rows.
