DESIGN (what landed)
-------------------------------------------------------------------------------
harness-core/src/media_delivery.rs (147 pure LOC, new):
  - DeliveryCapabilities {vision, audio_input} - Copy, Default ALL-FALSE
    (fail-closed). Core cannot depend on harness-intel (intel -> providers ->
    core), so the planner takes the capability slice as data; callers map
    from Catalog::capabilities at compose time.
  - WireBlock {Text | NativeImage{mime,media} | NativeAudio{mime,media} |
    Marker(String)}; WireBlock::text() = deterministic rendering (native
    blocks render "[image:|audio: <mime> <short-hash>]" - never bytes).
  - DeliveryPlan {wire, needed_projections: Vec<(MediaRef, ProjectionKind)>};
    queue stays populated even when a cached copy was inlined (queue = durable
    work list for the M10 pipeline, cache = optimization).
  - trait ProjectionCache {cached_projection(source, kind) -> Option<String>}
    + EmptyCache. Pure planner => map-backed in tests, DerivedStore-backed in
    production; planning is deterministic given (blocks, caps, cache).
  - plan() rules EXACTLY per plan line 144: image+vision -> NativeImage;
    image w/o vision -> Marker + needed SceneDescription (cached projection
    inlined as Text right after the marker when present); audio+audio_input ->
    NativeAudio else Marker + needed Transcript; ALL other media (incl.
    video/*, model/*, application/*) -> Marker + needed TextProjection (no
    provider ingests gltf/blend natively - honest). Queue deduped per
    (MediaRef, kind), first-seen order.
  - prefix_identity(prev, cur) = common byte prefix / prev len (empty prev =
    1.0); window_prefix_identity(prompts) = mean over consecutive pairs.
    THE metric definition the plan requires, test-pinned.

harness-providers/src/media.rs (97 pure LOC, new):
  - MediaDelivery::open(session_dir) - MediaStore + DerivedStore handles.
    load_bytes(hash) = request-build-time byte fetch.
    impl ProjectionCache: canonical producer const
    DELIVERY_PROJECTION_PRODUCER = "delivery"; DerivedCorrupt degrades to a
    miss with tracing::warn (marker renders + projection stays queued for
    repair - never a silent pass-through of corrupt data).
  - NativeMedia {kind: NativeKind, mime, hash, #[serde(skip)] bytes} - bytes
    NEVER serialize (snapshots keep refs only) and Debug prints
    "NB (redacted)" (in-crate test pins no byte ever prints).
  - native_mimes(family) DATA table: anthropic images only (Messages image
    source types; no audio input in M7-cited docs); openai images + wav/mp3
    (image_url + input_audio); google images + flac/mpeg/ogg/wav
    (inline_data; PDF-via-inline_data = NAMED FOLLOW-UP, NOT v0.2);
    xai images only (image_url); compat/unknown -> empty (fail-closed).
    Extendable per model without planner changes - the planner plans
    capabilities, the table gates dialects.

harness-providers/src/adapters/wire_media.rs (125 pure LOC, new):
  - anthropic_content / chat_content / google_parts / responses_input:
    text-only turns keep the EXACT pre-M8 plain-string forms (byte-compat -
    the existing cassette_conversation replay test still passes untouched);
    media turns become block arrays: Anthropic image source {type:base64,
    media_type, data}; chat image_url data: URL + input_audio {data,
    format: wav|mp3}; Google inline_data {mime_type, data}; Responses
    input_image/input_audio data-URL parts. Base64 exists ONLY in these
    rendered values. Family-kind combinations that cannot exist through the
    adapter boundary (serde-deserialized edge) warn + skip, never fabricate.

harness-providers/src/identity.rs (+~15 lines):
  - CompletionRequest.media: Vec<NativeMedia> with #[serde(default)] +
    with_native_media builder. TurnId UNCHANGED: it derives from the prompt,
    which already embeds every planned block's hash-keyed marker (same media
    => same id with or without payloads).

harness-providers/src/adapter.rs (202 pure LOC, rewritten rendering):
  - InferenceAdapter::new() keeps its signature (daemon + tests unchanged);
    new builders with_capabilities / with_media_delivery.
  - FAIL-CLOSED COUPLING: without a MediaDelivery the adapter plans
    text-only even with caps set (it cannot fetch bytes, so it does not
    promise them). The shipped daemon (which attaches neither until M32)
    therefore stays marker-only - honest.
  - render_blocks replaces the M3-era `ContentBlock::Image(_) | Media(_) =>

    tracing::debug (M10 consumes the queue).

Codec render_request changes (anthropic.rs / chat.rs / google.rs /
responses.rs, ~1 line each): content/parts/input now route through
wire_media::*.
