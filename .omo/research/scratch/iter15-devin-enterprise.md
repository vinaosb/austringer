## 2) ENTERPRISE GOVERNANCE

- **Architecture constraint (the big one):** [Enterprise Deployment](https://docs.devin.ai/enterprise/deployment/overview.md) — Devin = **Brain + Devbox**; the **brain always resides in Cognition's Cloud** even on Customer Dedicated Deployment (single-tenant VPC, AWS PrivateLink/IPSec). No customer LLM API keys ("compound AI system"). Enterprise Assured adds **Customer Managed Keys** (AWS KMS): [CMK doc](https://docs.devin.ai/enterprise/security-access/security/customer-managed-keys.md). **Outposts** (Jul 22, 2026) is the true self-hosted-worker tier: [overview](https://docs.devin.ai/cloud/outposts/overview.md), [reference](https://docs.devin.ai/cloud/outposts/reference.md).
- **Identity:** SAML / OIDC / Okta / Entra SSO guides + SCIM 2.0 (GA Jul 29, 2026) + IdP groups: [SSO guide](https://docs.devin.ai/enterprise/security-access/sso/guide.md), [SCIM](https://docs.devin.ai/enterprise/security-access/scim.md), [IdP groups](https://docs.devin.ai/enterprise/security-access/idp-groups.md). Custom roles/RBAC with delegable "Manage security profiles" permission: [custom roles](https://docs.devin.ai/enterprise/security-access/custom-roles.md).
- **Audit logs:** enterprise audit log incl. Devin Local settings changes (Jul 29, 2026); v3 API audit endpoints (Dec 12, 2025).
- **Network control:** enterprise **IP Access Lists** via Enterprise API v3, extended to automation webhooks Jul 31, 2026: [IP lists](https://docs.devin.ai/enterprise/security-access/ip-access-lists.md). Devin VPN (non-MFA) config: [vpn.md](https://docs.devin.ai/onboard-devin/vpn.md).
- **Security Profiles** ([doc](https://docs.devin.ai/product-guides/security-profiles.md), GA Aug 7, 2026): named bundles of network allowlist (hostnames/CIDR), MCP-server allowlist, Devin-MCP read-only, git access level (read-only/full), gh-token removal. **5-level binding hierarchy** (enterprise default → org default → automations default → automation → session) with **mandatory enforcement = intersection semantics** (lower levels can only tighten; mid-session grants clamped). - **AI Guardrails** (prompt-injection/exfiltration/policy screening): [doc](https://docs.devin.ai/enterprise/features/ai-guardrails.md); **Attribution Filtering** (blocks public-repo matches before write): [doc](https://docs.devin.ai/enterprise/features/attribution-filtering.md).
