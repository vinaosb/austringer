[[research-companion]]
== What this page indexes

The project was designed from a working research artifact: the file
`.omo/research/harness-research.md` — a 33-section study of 25+ agent
harnesses, built from pinned source snapshots, git archaeology, and
post-mortems. It stays Markdown because it is alive; this page is its
index. The repository README links the file directly; read it there.

The receipts rule: an adopted or avoided decision in this codebase is
traceable to a research-file section. The table below maps the sections to
what this project took from each.

[[companion-rule]]
== The rule, restated

A pull request that introduces a mechanism without a receipt will be asked
for one (see the evidence-culture section of the repository CONTRIBUTING).
A pull request that removes a guard will be asked which measured pathology
it intends to re-admit. The research file is the shared vocabulary for
both conversations.
